## 1. HSAD_LG 베스트샵 리테일 플랫폼
- 배경: 매장 점검·POP 부착 평가 등 오프라인 운영 업무가 수기로 진행됨
- 내 역할: RFP 분석·제안서·PT 참여로 수주, 관리자 IA·기능 정의·CMS 구조 설계
- 핵심 설계: 매장·관리자·본사 3층위 권한 구조, 콘텐츠 등록·필터/카테고리·GNB 자동 생성 고려한 관리자 구조, 운영 업무 순서 기반 IA
- 시스템 구성: One-Stop System(제작물 요청~배송 단일 흐름), Schedule Management(POP 배포·행사·매장 오픈 일정), Administrator System(가이드라인·POP·승인 플로우)
- 협업: 디자인-퍼블리싱-개발 동시 작업용 컴포넌트 단위 설계 가이드 작성, 운영팀 인터뷰 기반 플로우 설계
- 성과: 수기 업무 CMS 전환, 매장·운영팀·디자인/영업 간 커뮤니케이션 비용 감소 `[정량 수치 없음]`

## 2. 삼성 헬스케어·메디슨 글로벌 CMS
- 배경: 2016년 구축 CMS에 예외 처리 누적, 국가별 퍼블리싱 결과 불일치, H1/H2 중복 등 SEO 구조 문제
- 내 역할: RFP를 "운영 대행"이 아닌 "CMS 재정립"으로 재정의해 제안 전략 수립, 제안서 총괄·PT, 수주 후 PM
- 핵심 결정: 운영자 교육(체크리스트) 대신 **컴포넌트 기반 템플릿으로 SEO 규칙을 구조적으로 강제**
- 수행: GE·Philips 등 경쟁사 벤치마킹, SEO 컨설턴트 가이드를 운영자 입력 구조로 변환, 국가별 GA 태깅 재정의, GDPR·보안 대응 프로세스 정립, 월간 리포트·정기 미팅 체계
- 성과: 9개 사이트(헬스케어 7 + 메디슨 2), **퍼블리싱·개발 리드타임 5~8일 → 1~3일**
- 회고: 구조 변경 후 일부 국가 운영팀 적응 지연 → 이후 변경 사항 운영 가이드 동시 배포 절차 추가

## 3. HSAD AI 에이전트 플랫폼 (SI 클라이언트 프로젝트)
- 배경: 외부 기업 판매용 SaaS AI 플랫폼. 인텐트 분석·빅데이터 시장분석·콘텐츠 생성 3개 AI 솔루션을 대시보드형 허브로 통합
- 내 역할: RFP 분석·제안서 기술 파트·PT 참여, 수주 후 프론트 PM
- 문제: 솔루션마다 데이터 형태가 달라 20개+ 시각화 모듈의 화면 문법이 흩어질 위험
- 핵심 결정: 모듈별 개별 설계 대신 **데이터 명세 기반 공통 규칙 우선** — 필터-차트-상세 3단 구조 고정, 데이터 유형별 차트 매핑 규칙표
- 수행: 데이터 명세 우선 접근, 협업사 대상 API 설계 가이드 작성, 영향도·난이도 기준 우선순위 조율, 스프린트별 데모
- 성과: 20개+ 모듈 일관된 화면 규칙, 연동 해석 차이로 인한 재작업 감소 `[정량 수치 없음]`
- 회고: 공통 규칙 수립 기간을 일정에 미리 반영하지 않아 초반 일정 압박

## 4. 삼성DS 공식 홈페이지 운영
- 신규 행사 페이지 제작, CMS 반복 업무 최소화 등록 구조 개선안 제안
- Git 액세스 키 노출 보안사고 시 고객사 리포트·대응 시트·재발방지 프로세스 수립
- 운영 이슈 우선순위 정리, 고객사·외주 개발사 일정·기획 조율

## 5. 블라썸클라우드 반영구 실습 App
- 피부미용 교육기관 대상 반영구 화장 실습 네이티브 앱
- 펜슬 필압 기반 드로잉(눈썹 드로잉, 바늘 시뮬레이션, 강도 조절) 기능 정의
- iOS/AOS 네이티브 개발사와 OS별 필압 반응 차이 조율해 동일 UX 구현, 기획~테스트 단독

## 6. 라오나크 도소매점 B2C App

- 외부 시스템 API 연동 설계·문서화, 일정 관리 및 기획-디자인-개발 QA 리딩
