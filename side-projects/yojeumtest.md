# 요즘 유행 테스트 — 트렌드 성향 테스트 플랫폼

> 정리 기준일: 2026-10-16 · 작성 규칙: 레포 루트 CLAUDE.md
> `[확인 필요]` 항목은 사실 확인 전 이력서·면접에 사용하지 않는다.

## 1. 설계 원칙
- 유행이 바뀔 때마다 테스트를 빠르게 갈아끼울 수 있는 구조
- 테스트 하나 = 데이터 파일 하나 → 목록·진행·결과 페이지·사이트맵·공유 이미지 자동 생성
- FC 사이트와 분리된 독립 프로젝트·도메인

## 2. 타임라인
- 1일차: 먼작귀 → 강아지 8종 → 20종 → 산리오 → 늙크크 → 이미지 저장 버그 수정 → 첫 배포
- 2일차: 늙크크 3단계 개편 → 도메인 → GA4·개인정보 처리방침 → 소개 → 메타·구조화 데이터 → 색인 점검 수정 → 카카오·X 공유 → 먼작귀 바이럴 3종 → 검색 노출 보강
- 3일차: 전체 재점검, Search Console 사이트맵 제출

## 4. 시스템 설계
- 채점 엔진 3종: count(결과 8개 이하, 결과별 최대 점수 균등) / profile(성향 축 프로필 방향 비교, 결과 추가 용이) / grid(축별 % 구간)
- 이미지 교체 구조: 기본 팬아트 SVG, 같은 이름 png·webp 넣으면 자동 교체
- 결과 공유: 결과별 정적 페이지, 개인 응답은 브라우저 세션에만 저장

## 5. 문제 해결 사례 (STAR)
- **① 견종 결과 쏠림**: 2만 회 시뮬레이션에서 닥스훈트 약 30%·코기 약 23% → 원인(평균 수렴 + 문항 편향) → 코사인 유사도 + 축별 기준점 보정 → 최다 약 10%·최소 약 2.5%, 20종 모두 1위 가능 자동 테스트로 보장
- **② 결과 이미지 저장 오류**: 디버그 모드로 재현, 원인 3가지(SVG 크기 정보 없음, box-shadow 테두리, 인앱 브라우저 다운로드 차단) → SVG 45장 수정, 저장 흐름 재설계
- **③ 배포 후 검색 노출 결함 4건**: robots.txt 공유 이미지 차단(AI 설정 실수), 내부 링크 0개, vercel.app 중복 노출, 사이트맵 수정일 일괄 갱신 → 전부 수정, 90개 주소 크롤링 점검 정례화
- **④ 카카오 공유 에러 4019**: 공식 문서 대조로 콘솔 설정 문제로 판단 → JavaScript SDK 도메인 미등록 해결, SDK 버전 고정 + SRI
- **⑤ 캐릭터 저작권 리스크**: 공식 이미지 직접 배포 대신 리스크 설명 + 파일 교체 구조 + 공유 카드 팬아트 고정 + 저작권 고지
- **⑥ 유행 신선도**: 2026년 6~10월 트렌드 재조사 → 지금/올해 초/옛날 3단계 개편, "반년 늦은 트렌드러" 결과 신설

## 6. 바이럴·성장 설계
친구 궁합 루프, 질문 없는 이름 생성기, 결과별 공유 카드 + 카카오 버튼, 테스트 간 연결

## 7. 운영·인프라
Vercel 자동 배포, 가비아 도메인·DNS 직접 설정, GA4 맞춤 이벤트(시작·완료·공유·저장·궁합 완료 등), 검색 노출(제목·FAQ·구조화 데이터·사이트맵 90개·Search Console), 개인정보 처리방침·소개·팬 콘텐츠 고지, 애드센스 준비 전략
