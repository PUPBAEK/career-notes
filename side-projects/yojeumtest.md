## 1. 배경

- **문제 정의**: 먼작귀·산리오 같은 캐릭터나 유행 밈으로 하는 성향 테스트는 공유가 잘 되지만, 유행 주기가 짧아 콘텐츠가 금방 낡는다. 한 번 만들고 끝나는 테스트가 아니라 **유행이 바뀔 때마다 새 테스트를 빠르게 추가하는 한 곳**이 필요했다.
- **목표**: 유행 소재 테스트를 한 사이트에 계속 쌓아 두고, 공유로 유입되는 구조를 만든다. 장기적으로 광고 수익화를 검토한다.
- **설계 원칙**: 테스트 하나 = 데이터 파일 하나. 파일을 추가하면 목록·진행·결과 페이지·사이트맵·공유 이미지가 자동으로 생긴다.

## 4. 문제 해결 (STAR)

### ① 결과가 특정 견종으로 쏠리는 문제
- **상황**: 견종을 20종으로 늘리며 채점을 성향 프로필 방식으로 바꿈.
- **과제**: 20종이 고르게 나와야 함(이론상 약 5%씩).
- **행동**: (AI) 무작위 응답 2만 회 시뮬레이션 → 닥스훈트 약 30%, 코기 약 23%로 쏠림 확인. 원인을 "답이 섞이면 성향 평균이 가운데로 몰려 중간형 프로필이 이김" + "선택지 점수가 특정 축에 치우침"으로 규명. 거리 비교를 방향 비교(코사인 유사도)로 바꾸고, 축마다 선택지 평균을 기준점으로 삼아 편향 상쇄.
- **결과**: 최다 결과 약 10%, 최소 약 2.5%로 완화. 20종 모두 실제로 1위가 될 수 있음을 자동 테스트로 보장. 산리오 테스트에도 같은 방식 적용(구데타마 약 17% → 약 15%, 여전히 가장 높음).
- **내 역할**: 견종 확대 요구, 결과 확인·승인. 분석과 수정은 AI.

### ② 결과 이미지 저장 시 이미지가 안 나오는 문제
- **상황**: 본인이 "이미지 저장을 누르면 안 나오는 경우가 있다"고 제보.
- **행동**: (AI) 캡처 결과를 화면에 띄우는 임시 디버그 모드로 재현 → 원인 3가지 규명: 일러스트 SVG에 크기 정보 없음, 캡처 라이브러리가 그림자 방식 테두리를 못 그림, 카카오톡·인스타그램 인앱 브라우저와 일부 iOS의 다운로드 차단. 당시 SVG 45장 전부 수정, 저장 흐름을 "미리보기 → 모바일 공유 시트 / PC 다운로드 → 길게 눌러 저장 안내"로 재설계.
- **결과**: 수정 후 캡처로 재검증. [확인 필요: 인앱 브라우저 실기기 저장 동작]
- **내 역할**: 문제 발견·제보, 배포 후 확인.

### ③ 배포 후 점검으로 찾은 검색 노출 결함 4건
- **상황**: 본인이 "색인 잘 되게 설정한 거 맞아?"라고 재확인 요청.
- **행동**: (AI) 실제 사이트를 검색엔진 시점으로 재점검 → ① robots.txt가 공유 이미지 경로까지 차단(**AI가 앞서 만든 설정의 실수**) ② 테스트 페이지 → 결과 페이지 내부 링크 0개 ③ 예전 vercel.app 주소가 같은 내용 중복 노출 ④ 사이트맵 수정일이 배포마다 전부 갱신.
- **결과**: 4건 모두 수정·재확인. 이후 사이트맵 전체 주소를 크롤링해 상태코드·제목·설명·canonical·H1·구조화 데이터·공유 이미지를 확인하는 점검 스크립트 운영(최종 90개 주소 문제 없음).
- **내 역할**: 재검증 요구. **AI 산출물도 검증해야 한다는 판단이 실제 결함을 잡은 사례.**

### ④ 카카오톡 공유 인증 실패 (에러 4019)
- **상황**: 카카오 키 연결 후 공유하면 인증 실패 오류.
- **행동**: (본인) 오류 화면·콘솔 화면 공유, 키 재확인 / (AI) 오류 안내문과 공식 문서를 대조해 코드가 아닌 콘솔 설정 문제로 판단. 처음 받은 값이 앱 실행용 키(웹용 아님)였음을 짚고, 도메인 등록 위치를 단계별로 안내.
- **결과**: JavaScript SDK 도메인 미등록이 원인 → 해결, 본인이 실기기에서 공유 동작 확인. SDK는 버전 고정 + 무결성 해시로 로드.

### ⑤ 캐릭터 저작권 리스크 관리
- **상황**: 본인이 공식 캐릭터 이미지를 쓰고 싶다고 요청.
- **행동**: (AI) 공식 이미지를 대신 받아 배포하지 않고 리스크(삭제 요청, 광고 제한)를 설명, 파일만 넣으면 교체되는 구조 제공 / (본인) 이미지를 직접 준비해 적용 결정.
- **결과**: 운영자가 리스크를 알고 결정하는 구조. 링크 공유 카드는 항상 팬아트, 전 페이지 팬 콘텐츠·저작권 고지. 애드센스 신청 전 팬아트로 되돌리는 계획 [확인 필요: 실행 여부].

### ⑥ 유행 콘텐츠의 신선도
- **상황**: 늙크크 테스트의 "요즘 유행" 일부가 2026년 1~2월·2025년 유행이었음.
- **행동**: (본인) 2026년 현시점 유행 재조사 요청 / (AI) 2026년 6~10월 월별 트렌드 리포트로 재조사, 출처가 불확실한 항목은 제외하고 보고, "지금 / 올해 초 / 옛날" 3단계 개편안 제시.
- **결과**: 18문항·결과 7종·3축 판정으로 개편, "반년 늦은 트렌드러" 결과 신설. 유행이 바뀌면 "지금 → 올해 초"로 내리기만 하는 운영 구조.
