> 주의: HSAD AI 에이전트는 **나인파이브가 SI로 수주한 클라이언트(HSAD) 프로젝트**다. 제품은 HSAD 소유이며 본인은 나인파이브 측 프론트 PM.

- 배경: 외부 기업 판매용 SaaS AI 플랫폼. 인텐트 분석·빅데이터 시장분석·콘텐츠 생성 3개 AI 솔루션을 대시보드형 허브로 통합
- 내 역할: RFP 분석·제안서 기술 파트·PT 참여, 수주 후 프론트 PM
- 문제: 솔루션마다 데이터 형태가 달라 20개+ 시각화 모듈의 화면 문법이 흩어질 위험
- 핵심 결정: 모듈별 개별 설계 대신 **데이터 명세 기반 공통 규칙 우선** — 필터-차트-상세 3단 구조 고정, 데이터 유형별 차트 매핑 규칙표
- 수행: 데이터 명세 우선 접근, 협업사 대상 API 설계 가이드 작성, 영향도·난이도 기준 우선순위 조율, 스프린트별 데모
- 성과: 20개+ 모듈 일관된 화면 규칙, 연동 해석 차이로 인한 재작업 감소 `[정량 수치 없음]`
- 회고: 공통 규칙 수립 기간을 일정에 미리 반영하지 않아 초반 일정 압박
